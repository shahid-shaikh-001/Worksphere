# 🚀 Installation & Setup

## 1️⃣ Clone Repository

```bash id="xq2t6l"
git clone https://github.com/shahid-shaikh-001/Worksphere.git
cd Worksphere
```

---

## 2️⃣ Setup Backend

```bash id="3h3e9s"
cd Backend
npm install
```

Create `.env` file inside Backend folder:

```env id="kw6j8o"
PORT=5000
DATABASE_URL=YOUR_DATABASE_URL
CLERK_SECRET_KEY=YOUR_CLERK_SECRET
CLERK_PUBLISHABLE_KEY=YOUR_CLERK_KEY
INNGEST_EVENT_KEY=YOUR_INNGEST_KEY
```

Run backend server:

```bash id="o6v2dx"
npm run dev
```

---

## 3️⃣ Setup Frontend

```bash id="4d5k3v"
cd Frontend
npm install
npm run dev
```
